FIRE FIGHTING ROBOT

An Arduino-based smart robotic system designed to detect fire and assist in firefighting operations using flame sensors, motors and a water pump.

Explore Project →

About Project

Introduction to our Fire Fighting Robot

The Fire Fighting Robot is an Arduino-based robotic project developed to detect a flame and respond automatically. It uses flame sensors to identify the direction of a flame. The Arduino processes the sensor signals and controls the movement of the robot. A servo motor helps position the water nozzle, while a pump system is used for water delivery.


This project demonstrates the application of robotics, electronics, sensors and automation in a practical engineering model.

Project Objectives

Main goals of the project

01. Fire Detection

To detect flame using flame sensors.

02. Automation

To control robot movement automatically using Arduino.

03. Safety

To demonstrate a remote-free robotic response concept.

04. Learning

To understand robotics, sensors and embedded systems.

Working Principle

How the Fire Fighting Robot works

Step 1 – Flame Detection

Flame sensors detect the presence of a flame.

Step 2 – Signal Processing

Arduino receives the sensor signals and processes them.

Step 3 – Robot Movement

The motor driver controls the robot motors according to the sensor readings.

Step 4 – Robot Stops

When the flame is detected, the robot stops its movement.

Step 5 – Nozzle Positioning

The servo motor positions the water nozzle.

Step 6 – Water Pump

The pump control system is activated to deliver water.

Arduino Source Code

Basic example program for the robot

FireFightingRobot.ino 
#include <Servo.h>

#define LEFT_FLAME A0
#define RIGHT_FLAME A1

#define IN1 2
#define IN2 3
#define IN3 4
#define IN4 5

#define ENA 9
#define ENB 10

#define SERVO_PIN 6
#define PUMP_PIN 7

#define FLAME_ACTIVE LOW

Servo nozzle;

void stopMotors() {
  digitalWrite(ENA, LOW);
  digitalWrite(ENB, LOW);

  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
}

void moveForward() {
  digitalWrite(ENA, HIGH);
  digitalWrite(ENB, HIGH);

  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
}

void setup() {
  pinMode(LEFT_FLAME, INPUT);
  pinMode(RIGHT_FLAME, INPUT);

  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);

  pinMode(ENA, OUTPUT);
  pinMode(ENB, OUTPUT);

  pinMode(PUMP_PIN, OUTPUT);
  digitalWrite(PUMP_PIN, LOW);

  nozzle.attach(SERVO_PIN);
  nozzle.write(90);

  Serial.begin(9600);
  stopMotors();
}

void loop() {
  int leftValue = digitalRead(LEFT_FLAME);
  int rightValue = digitalRead(RIGHT_FLAME);

  if (leftValue == FLAME_ACTIVE ||
      rightValue == FLAME_ACTIVE) {

    stopMotors();

    if (leftValue == FLAME_ACTIVE) {
      nozzle.write(45);
    }
    else if (rightValue == FLAME_ACTIVE) {
      nozzle.write(135);
    }

    // D7 is a control signal only.
    // Use a properly rated external pump driver.
    digitalWrite(PUMP_PIN, HIGH);
    delay(3000);

    digitalWrite(PUMP_PIN, LOW);
    nozzle.write(90);
  }
  else {
    moveForward();
  }

  delay(100);
}

Important: Do not connect the water pump directly to an Arduino output pin. D7 must control a properly rated driver; the pump needs a suitable external power supply and safe wiring.
