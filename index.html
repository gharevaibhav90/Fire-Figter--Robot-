INTRODUCTION

About Our Project

Understanding the concept behind our Fire Fighting Robot.

What is a Fire Fighting Robot?

A Fire Fighting Robot is a robotic system designed to detect fire and assist in firefighting operations. It uses electronic sensors, a microcontroller, motors and a water pump.

Our project uses an Arduino Uno as its main controller. Two flame sensors detect fire-related infrared signals.

When a flame is detected, the robot stops its movement, the servo motor changes the nozzle direction and the water pump is activated through a suitable driver circuit.

PROJECT OVERVIEW

Problem Statement

Why do we need an automatic firefighting system?

Fire accidents can cause serious damage to human life, property and the environment. In dangerous areas, it may be difficult for people to approach the fire directly. Manual firefighting can also expose people to risk.


Therefore, we are developing a small Arduino-based Fire Fighting Robot that can detect a flame and activate a basic water-spraying mechanism. The project demonstrates how automation and robotics can assist in firefighting.

ELECTRONICS

Electronic Circuit Diagram

Conceptual connection layout of the main electronic components.

Arduino Based Fire Fighting Robot

Connection Notes:
  • Left flame sensor output: Arduino A0.
  • Right flame sensor output: Arduino A1.
  • L298N input pins: D2, D3, D4 and D5.
  • L298N enable pins: D9 and D10.
  • Servo signal pin: D6.
  • Pump driver control signal: D7.
  • Connect circuit grounds appropriately.
  • Never power the pump directly from an Arduino I/O pin. Use a suitable driver and power supply.

PROGRAMMING

Arduino Source Code

Example control logic for the Fire Fighting Robot.

Fire_Fighting_Robot.ino


#include <Servo.h>

#define LEFT_FLAME A0
#define RIGHT_FLAME A1

#define IN1 2
#define IN2 3
#define IN3 4
#define IN4 5

#define ENA 9
#define ENB 10

#define SERVO_PIN 6
#define PUMP_PIN 7

#define FLAME_ACTIVE LOW

Servo waterServo;

void stopMotors() {
  digitalWrite(ENA, LOW);
  digitalWrite(ENB, LOW);

  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
}

void setup() {
  Serial.begin(9600);

  pinMode(LEFT_FLAME, INPUT);
  pinMode(RIGHT_FLAME, INPUT);

  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);

  pinMode(ENA, OUTPUT);
  pinMode(ENB, OUTPUT);

  pinMode(PUMP_PIN, OUTPUT);
  digitalWrite(PUMP_PIN, LOW);

  waterServo.attach(SERVO_PIN);
  waterServo.write(90);

  stopMotors();
}

void loop() {
  int leftValue = digitalRead(LEFT_FLAME);
  int rightValue = digitalRead(RIGHT_FLAME);

  Serial.print("Left: ");
  Serial.print(leftValue);

  Serial.print(" Right: ");
  Serial.println(rightValue);

  bool fireDetected =
    (leftValue == FLAME_ACTIVE ||
     rightValue == FLAME_ACTIVE);

  if (fireDetected) {
    stopMotors();

    waterServo.write(45);
    delay(700);

    waterServo.write(135);
    delay(700);

    waterServo.write(90);

    // D7 controls a suitable pump driver.
    // Never connect the pump directly to D7.
    digitalWrite(PUMP_PIN, HIGH);
    delay(3000);
    digitalWrite(PUMP_PIN, LOW);

  } else {
    digitalWrite(PUMP_PIN, LOW);
    stopMotors();
    waterServo.write(90);
  }

  delay(100);
}

Note: This is an example program. Verify sensor output polarity and wiring before use.

TECHNICAL REVIEW

Limitations

Current limitations of our prototype.

  • Flame sensor detection depends on distance and surrounding light conditions.
  • The robot has limited water storage capacity.
  • Battery capacity affects operating time.
  • The prototype is for educational demonstration, not real emergency firefighting.
  • Its movement and navigation are limited to the implemented control system.
