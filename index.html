01 / INTRODUCTION

ABOUT OUR PROJECT

The Fire Fighting Robot is a student engineering project that combines mechanical design, electronics and programming. The robot uses two flame sensors to identify flame signals. Arduino processes these signals and controls the movement, servo motor and water pump.

The project demonstrates the fundamentals of embedded systems, automation and robotics in a controlled educational environment.

02 / PROJECT OVERVIEW

PROBLEM STATEMENT

Understanding the need for an automated fire-response prototype.

The Challenge

Manual fire response can involve risk and delays. This project explores a small robotic prototype that detects flame signals and demonstrates an automated response using a water pump. It is an educational model, not a certified firefighting device.

08 / ELECTRONICS

ELECTRONIC CIRCUIT DIAGRAM

Functional connection overview of the Fire Fighting Robot.

01. INPUT SECTION

Two flame sensors provide detection signals to Arduino Uno through A0 and A1.

02. CONTROL SECTION

Arduino Uno processes sensor signals and sends control signals to the output devices.

03. MOTOR SECTION

L298N motor driver controls the two TT DC motors using Arduino control signals.

04. SERVO SECTION

Servo motor receives its control signal from Arduino digital pin D6.

05. PUMP SECTION

Arduino D7 provides a control signal to a suitable pump switching driver.

06. POWER SECTION

Use suitable power supplies for the Arduino, motors, servo and pump as required by their ratings.

IMPORTANT ELECTRICAL NOTE: This is a conceptual connection diagram, not a verified final wiring schematic. Never connect the water pump directly to an Arduino GPIO pin. Use a properly rated switching driver and suitable external supply. Check component voltage/current ratings, wiring and common-ground requirements before powering the prototype.
09 / PROGRAMMING

ARDUINO SOURCE CODE

Illustrative program structure for the project.

● ● ● 
// Fire Fighting Robot
// Group No. 3
// Vaibhav Ghare
// Krushna Fapale

#include <Servo.h>

const int LEFT_FLAME = A0;
const int RIGHT_FLAME = A1;

const int IN1 = 2;
const int IN2 = 3;
const int IN3 = 4;
const int IN4 = 5;

const int SERVO_PIN = 6;
const int PUMP_DRIVER_PIN = 7;

Servo waterServo;

void stopMotors() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
}

void setup() {
  pinMode(LEFT_FLAME, INPUT);
  pinMode(RIGHT_FLAME, INPUT);

  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);

  pinMode(PUMP_DRIVER_PIN, OUTPUT);
  digitalWrite(PUMP_DRIVER_PIN, LOW);

  waterServo.attach(SERVO_PIN);
  waterServo.write(90);

  Serial.begin(9600);
}

void loop() {
  int left = digitalRead(LEFT_FLAME);
  int right = digitalRead(RIGHT_FLAME);

  Serial.print("Left: ");
  Serial.print(left);
  Serial.print(" Right: ");
  Serial.println(right);

  if (left == LOW || right == LOW) {
    stopMotors();

    if (left == LOW) {
      waterServo.write(60);
    } else if (right == LOW) {
      waterServo.write(120);
    }

    // This pin controls a suitable pump driver.
    digitalWrite(PUMP_DRIVER_PIN, HIGH);
  } else {
    digitalWrite(PUMP_DRIVER_PIN, LOW);
    waterServo.write(90);
  }

  delay(100);
}

Note: This is an illustrative code example. Confirm your flame sensor output logic, motor driver connections and pump driver circuit before using it on your robot.
