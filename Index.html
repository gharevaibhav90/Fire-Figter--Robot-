About Project

The Fire Fighter Robot is an innovative robotics project designed to detect fire using flame sensors. It uses Arduino Uno to control the robot movement and a water pump system.

Components Used

  • Arduino Uno
  • 2 Flame Sensors
  • 2 TT DC Motors
  • L298N Motor Driver
  • Servo Motor
  • Mini Water Pump
  • Battery and Connecting Wires

Working Principle

1. Flame sensors detect fire.

2. Arduino receives sensor signals.

3. Robot stops when fire is detected.

4. Servo motor turns towards the target.

5. Water pump activates to extinguish the fire.

Project Objectives

  • Automatic fire detection
  • Robotics and automation
  • Arduino-based control
  • Fire safety assistance
